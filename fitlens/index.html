How to install Fit Lens

Fit Lens ships as an Android APK (it isn't on the Play Store yet). Installing takes about 30 seconds.

  1. Tap Download to get fitlens.apk.
  2. Open the file from your notifications or your Downloads folder.
  3. If Android asks, allow your browser or file manager to install from this source.
  4. Tap Install, then Open — and start scanning food.

Heads up: Android shows a generic "unknown source" warning for every APK outside the Play Store. The Fit Lens file is verified 0/74 on VirusTotal — see the report below.
